# Sprite packs

Clawd Buddy draws its character from **sprite packs**: a folder with a `manifest.json` and image files.

## Clawd

Clawd is Anthropic's mascot, and there is no official distribution of his sprites that permits redistribution, so this repository ships only an **original stand-in character ("Pip")**, generated by `scripts/generate-placeholder.mjs`. It is not Clawd and is never presented as Clawd.

To use the real Clawd, install the Claude desktop app and choose **Settings → Character & sprites → Import Clawd from the Claude app**. That writes a pack named `clawd` into your user folder from your own installation (see [ARTWORK.md](../../ARTWORK.md)).

You can also add artwork you're permitted to use as described below. **Don't commit non-redistributable artwork to the repository**; `.gitignore` excludes `assets/sprites/local/` and every sprite folder other than `placeholder/`.

## Where packs are loaded from

In priority order:

1. **Your user folder**: `%APPDATA%\Clawd Buddy\sprites\<pack-name>\` on Windows, `~/Library/Application Support/Clawd Buddy/sprites/<pack-name>/` on macOS. Open it from *Settings → Character & sprites → Open sprite folder*.
2. **Developer-local folder**: `assets/sprites/local/<pack-name>/` (only when running from source; git-ignored).
3. **Built-in placeholder**: `assets/sprites/placeholder/`.

With the setting *Use pack: Automatic*, the first valid pack from (1) or (2) wins, and the placeholder is used otherwise. You can also pick a pack explicitly.

## Manifest format

See [`manifest.example.json`](manifest.example.json).

| Field | Meaning |
| --- | --- |
| `name` | Display name |
| `official` | Set to `true` only if the artwork really is official. The app shows it as "declared official (unverified)", because it cannot check provenance itself. |
| `author`, `source`, `license`, `attribution` | Provenance and usage terms, shown in the diagnostics panel. Fill these in honestly. |
| `frameWidth`, `frameHeight` | Size of one frame in pixels (8–512). Art is scaled up with crisp nearest-neighbor scaling to a whole number of device pixels per art pixel. All frames share this size; align the character the same way in every frame (e.g. feet on the bottom row) so animations don't jitter. |
| `bodyBox` | Optional `[x, y, width, height]` of the character's standing body inside a frame. Used to keep the character (not the transparent frame around it) on screen and to place the speech bubble. Defaults to the whole frame. |
| `animations` | Map of animation name → definition, or → an **array** of definitions (variants; one is picked each time) |

Each animation (or variant) is either:

- `{"frames": ["a.png", "b.png"], "fps": 6, "loop": true}`, with one image per frame, or
- `{"sheet": "walk.png", "frameCount": 4, "fps": 8, "loop": true}`, a horizontal strip of `frameCount` frames.

Optional fields: `"loopStart": 2` (an intro of frames 0–1 plays once, then frames 2… loop) and `"label": "Hula"` (shows the variant in the *Do a trick* menu).

Animation names: `idle` (required), `idle-variation`, `walk`, `think`, `talk`, `happy`, `confused`, `idea`, `sleep`, `wake`, `action`, `wave`, `pickup`, `drag` (the carried pose while held), and `land`. Any missing animation falls back automatically (for example `drag → pickup → action → idle`, `land → idle`), so a pack containing only `idle` still works; the app then adds its own squash-and-stretch for pickup and landing. Sprites should face **right**; the app mirrors them when walking left. One-shot animations (`loop: false`) last exactly `frames ÷ fps`.

Image paths must be simple relative paths (`frames/idle_0.png`). Absolute paths and `..` are rejected, and only PNG, GIF, and WebP files are served.

After adding or changing a pack, click **Reload sprites** in Settings. Problems such as invalid JSON, missing files, or missing `idle` are listed there. They never crash the app.
