# Sprite packs

Clawd Buddy draws its character from **sprite packs**: a folder with a `manifest.json` and image files.

## Why the official Clawd artwork isn't included

Clawd is Anthropic's mascot. As of this writing there is no official, publicly licensed distribution of Clawd sprite or animation files that permits redistribution in a third-party app. Community projects that draw Clawd generally note that the character remains Anthropic's intellectual property, and an MIT license on a repository covers its *code*, not the character design.

So this repository ships only an **original placeholder character ("Pip")**, generated by `scripts/generate-placeholder.mjs` and clearly labeled "placeholder art" in the app. It is not Clawd and is never presented as Clawd.

If you have artwork you are permitted to use (for example, your own drawings, or assets whose license allows it), you can add it locally as described below. **Don't commit non-redistributable artwork to the repository**; the `.gitignore` already excludes `assets/sprites/local/` and any sprite folder other than `placeholder/`.

## Where packs are loaded from

In priority order:

1. **Your user folder**: `%APPDATA%\Clawd Buddy\sprites\<pack-name>\` on Windows. Open it from *Settings → Character & sprites → Open sprite folder*.
2. **Developer-local folder**: `assets/sprites/local/<pack-name>/` (only when running from source; git-ignored).
3. **Built-in placeholder**: `assets/sprites/placeholder/`.

With the setting *Use pack: Automatic*, the first valid pack from (1) or (2) wins, and the placeholder is used otherwise. You can also pick a pack explicitly.

## Manifest format

See [`manifest.example.json`](manifest.example.json).

| Field | Meaning |
| --- | --- |
| `name` | Display name |
| `official` | Set to `true` only if the artwork really is official. The app shows it as "declared official (unverified)", because it cannot check provenance itself. |
| `author`, `source`, `license`, `attribution` | Provenance and usage terms, shown in the diagnostics panel. Fill these in honestly. |
| `frameWidth`, `frameHeight` | Size of one frame in pixels (8–512). Art is scaled up with crisp nearest-neighbor scaling. |
| `animations` | Map of animation name → definition |

Each animation is either:

- `{"frames": ["a.png", "b.png"], "fps": 6, "loop": true}`, with one image per frame, or
- `{"sheet": "walk.png", "frameCount": 4, "fps": 8, "loop": true}`, a horizontal strip of `frameCount` frames.

Supported animation names are `idle` (required), `walk`, `think`, `talk`, `happy`, `confused`, `sleep`, `wake`, and `action`. Any missing animation falls back automatically (for example `happy → action → idle`), so a pack containing only `idle` still works. Sprites should face **right**; the app mirrors them when walking left.

Image paths must be simple relative paths (`frames/idle_0.png`). Absolute paths and `..` are rejected, and only PNG, GIF, and WebP files are served.

After adding or changing a pack, click **Reload sprites** in Settings. Problems such as invalid JSON, missing files, or missing `idle` are listed there. They never crash the app.
