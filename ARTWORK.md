Artwork licensing is separate from the source-code license.

## What this repository contains

| Path | What it is | License |
| --- | --- | --- |
| `assets/sprites/placeholder/` | "Pip", an **original** placeholder character generated by `scripts/generate-placeholder.mjs` | MIT, same as the code |
| `assets/icons/` | Original app and tray icons (an orange speech bubble) generated by the same script | MIT, same as the code |

Neither of these depicts Clawd, and neither is Anthropic artwork.

## What it does not contain

**Clawd**, the orange pixel mascot associated with Claude Code, is Anthropic's character. I looked for an official, Anthropic-controlled distribution of Clawd sprite or animation files with terms that allow redistribution in a third-party app, and found none:

- Anthropic's documentation says very little about the mascot. Community write-ups, such as the [note.com article](https://note.com/nana_nonpro/n/n36dd09cd0858?hl=en) this project took as inspiration, cite no official asset source or license.
- Community fan projects that recreate Clawd (emoji generators, status-line mascots, "mascot maker" tools) license their **code** under MIT but state, or imply, that the character itself remains Anthropic's intellectual property.

Because of that, no Clawd artwork is bundled, scraped, or redistributed here. The app has an asset-provider system that loads sprite packs from a local folder outside the repository, so you can use artwork you are permitted to use. See [`assets/sprites/README.md`](assets/sprites/README.md).

If Anthropic publishes Clawd assets under terms that allow it, a pack could be added with its original notices kept intact.

## Contributor rules for artwork

- Contribute only artwork you created yourself or that is under a license compatible with redistribution here, and include its license and attribution.
- Never label generated or fan-made art as "official Clawd".
- Don't commit anything under `assets/sprites/local/` or any other non-placeholder sprite folder. These paths are git-ignored on purpose.
