## Clawd

**Clawd**, the orange pixel mascot of Claude Code, is Anthropic's character and artwork. This repository does **not** contain, bundle, or redistribute any Clawd artwork, and the packaged apps don't either.

### Where Clawd's animations come from

Researching sources (starting from the [note.com article](https://note.com/nana_nonpro/n/n36dd09cd0858?hl=en) this project took as inspiration, Anthropic's repositories and docs, and community projects) turned up no official, redistributable Clawd sprite package. It did show that Anthropic's own **Claude desktop app** contains Clawd's original pixel animations, used for the mascot inside that app. Several community tools already read them from the user's own installation rather than redistributing them.

Clawd Buddy does the same, only on the user's request (**Settings → Character & sprites → Import Clawd from the Claude app**):

- It locates the user's installed Claude desktop app (Windows: the Microsoft Store/MSIX install or the per-user install; macOS: `/Applications/Claude.app`).
- It reads one file, the app's `clawdQuestEngine-*.js` asset inside `app.asar`, **read-only**, and parses the sprite records in it as data. Nothing from the app is executed.
- It decodes each animation (a palette of 2–9 colors, a base frame, and per-frame pixel changes) and writes PNG strips plus a `manifest.json` into the user's own sprite folder (`%APPDATA%\Clawd Buddy\sprites\clawd` or `~/Library/Application Support/Clawd Buddy/sprites/clawd`).
- The pack's manifest records the source ("Claude desktop app … on this computer") and the terms: © Anthropic, imported for personal use on that computer, not for redistribution.
- Nothing is uploaded anywhere. The folder is outside the repository; `.gitignore` also excludes every sprite folder except the stand-in.

Using Anthropic's app assets this way, for yourself on your own computer, is your call. Don't share the generated pack, and don't commit it.

### How the original frames are used

Every frame is used as is: same pixels, palette, proportions, and outlines. Frames are only placed on a common canvas, aligned on Clawd's feet (the source animations' own anchor point), so switching animations never makes him jump. No frame is redrawn, recolored, or AI-generated.

| Clawd Buddy state | Original animation (frames) |
| --- | --- |
| idle | Walking, standing frame |
| idle variations | LookingAround, Swaying, Turning |
| walk | Walking (turn, then the 5-frame walk cycle) |
| pickup → carried → landing | Jumping (crouch and push-off; airborne arms-up loop; landing squash, rebound, settle) |
| think | Thinking (thought bubble with dots) |
| talk (reply streaming) | Laptop (typing loop) |
| happy | JumpingHappy, Excited, DancingHappy |
| confused / error | Dizzy, Facepalm, Disappointed |
| idea (fun facts) | Lightbulb |
| sleep / wake | Meditating (eyes-closed sitting loop / waking up) |
| wave (greetings, chat opens) | Waving |
| tricks | Hula, Pointing, CrabWalking, and the above |

Extra motion that has no frames of its own (a slight squash on pickup, a damped bounce on landing) is a scale transform applied to the sprite as a whole, never new drawing. Reduce motion turns it off.

If an app update changes an animation so a planned frame range no longer exists, that sequence is skipped and the app's normal fallbacks apply (ultimately the standing frame).
